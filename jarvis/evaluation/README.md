# `evaluation/` — V69 M62 S3C adapter evaluation

This tree holds the **inputs and outputs** of base-model-versus-adapter comparisons
driven by `python -m scripts.evaluate_adapter`. Nothing in it is committed except this
file, the `.gitignore` and the reviewed sample config: a generated evaluation quotes
held-out task material and both models' responses, and is reviewed locally.

## What lives here

```
evaluation/
  configs/qwen3-0.6b-adapter-eval.json   the reviewed template (tracked)
  evaluations/<id>/gen-<n>/              one evaluation generation (never committed)
  evaluation_runs.jsonl                  the plan-consumption ledger (never committed)
  evaluation_quarantine/                 generations that failed artifact validation
```

A generation directory holds exactly nine files, all digested by
`evaluation-manifest.json`, which is written last:

`evaluation-plan.json`, `task-pack.jsonl`, `task-pack-manifest.json`,
`baseline-results.jsonl`, `candidate-results.jsonl`, `paired-comparisons.jsonl`,
`metrics.json`, `evaluation-report.json`, `evaluation-manifest.json`.

Anything else in that directory is a verification failure, not a curiosity.

## Current status

**No adapter has been evaluated.** The production Transformers/PEFT evaluation backend
exists and its structure is reviewed and tested, but it has never been run against a
model — no weights have been loaded, no adapter has been attached and no token has been
generated by it. `--execute` refuses on every host, and the refusal names which
precondition is missing.

Every report this build can currently produce carries
`empirical_status: synthetic_only`, and a synthetic report can never make a candidate
eligible for human review.

See `docs/V69_M62_S3C_ADAPTER_EVALUATION.md` for the design and
`docs/ADAPTER_EVALUATION_RUNBOOK.md` for the exact commands.
