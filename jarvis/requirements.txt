#  DEPRECATED (V69 M61.3) — this file is no longer a dependency list.
# ═══════════════════════════════════════════════════════════════════════════
#
# It used to be a 170-line monolith that mixed text-mode, OCR, RAG and
# GUI-automation/offensive packages in one flat list, maintained independently of
# both `requirements/*.txt` and `pyproject.toml`. Three rival lists is how
# `pip install jarvis[soc]` and `pip install -r requirements/soc.txt` ended up
# producing different environments.
#
# THE AUTHORITY IS NOW `requirements/<profile>.txt`. `pyproject.toml` mirrors it
# and is verified by `core.dependency_authority.audit()`, a mandatory CI gate.
#
# Nothing is lost: every package this file declared was verified to be a strict
# subset of `requirements/all.txt` (90 packages, 0 legacy-only) before it was
# replaced, so `pip install -r requirements.txt` still resolves the same set.
# But `all` includes the offensive/lab and GUI-automation tooling — for a normal
# workstation install the profile you actually want:
#
#     pip install -r requirements/base.txt     # text mode (the default)
#     pip install -r requirements/voice.txt    # + STT / TTS
#     pip install -r requirements/docs.txt     # + document reading / OCR
#     pip install -r requirements/soc.txt      # + defensive SOC / DFIR
#     pip install -r requirements/dev.txt      # + tests / lint / scanners
#     pip install -r requirements/lab.txt      # LAB ONLY — offensive-capable
#     pip install -r requirements/all.txt      # everything, including lab
#
# Equivalently, from the package metadata (same contents, verified equal):
#
#     pip install .                            # base / text mode
#     pip install ".[voice,docs,soc,dev]"      # profiles as extras
#
-r requirements/all.txt
